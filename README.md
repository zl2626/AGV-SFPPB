# AGV-SFPPB

基于 MATLAB/Simulink 的 AGV 横向控制研究工程。项目继承原始 `AGV_TFS` 的车辆模型和 Simulink 主体结构，研究二维跟踪误差、单一转向输入及执行器约束下的滑模柔性规定性能边界（SFPPB）与 Identifier–Critic–Actor 强化学习控制。

> 当前版本已经完成 20 s 主基准、60/120 s 在线学习消融、30 组成对参数不确定性试验，以及 `0.50--0.30 rad` 执行器能力扫描。柔性边界在真实饱和时发挥了清晰作用；在线学习的平均方向基本正确，但相对冻结策略的收益仍小，且没有提高当前不确定性试验的成功率。因此当前定位仍是可复现的研究原型，而不是“已经完美”的最终论文控制器。

## 当前主线结论

- 二维 `z2` 始终保留到值函数梯度和唯一方向盘输入，不再使用固定 `P`、`C_gain`、`z2_control` 或标量投影。
- CARE/LQR 只提供可容许初始策略与控制方向上的值梯度种子；Actor 学习 Critic 共用值函数基底上的残差梯度，不再使用独立 direct-policy 特征。
- 控制量已经分解并记录为 `delta_admissible + delta_RL + delta_safety_correction`，可以直接辨认 RL 与安全层各自贡献。
- 60 s 和 120 s 消融中，在线学习降低总目标、控制能量和 `y` RMS，但 `phi` RMS 分别轻微增加 `0.048%` 和 `0.122%`；不能再表述为四项同时改善。
- 0.4 rad 真实饱和下，名义 `phi` 边界被短时突破，但柔性边界保持正裕量并在饱和结束后恢复，证明柔性机制不是闲置状态。
- 执行器扫描中 `0.375 rad` 仍通过 20 s，`0.35 rad` 及以下失败，当前可行能力边界位于二者之间；失败没有通过继续调参隐藏。

## 控制结构

```text
AGV plant
   -> SFPPB / NMT / first backstepping layer
   -> vector s1 and z2
   -> Identifier F_hat
   -> centered 4-D Critic value basis
   -> shared-basis value-gradient Actor
   -> SFPPB safety projection
   -> physical steering saturation
   -> AGV plant
```

### Identifier 与四维 Bellman 状态

```matlab
Z_F = [e_y; e_phi; de_y; de_phi];
z2_bar = z2 - O2;
X_H = [s1_y; s1_phi; z2_bar_y; z2_bar_phi];
```

四维状态导数保持闭合：

```text
s1_dot = -C1*s1 + D1*Sigma*(z2_bar + O2)
z2_bar_dot_hat = F_hat + C*delta_safe + O2
X_H_dot = [s1_dot; z2_bar_dot_hat]
```

Critic 与 Actor 共用中心化 RBF 基底 `S_J(X_H)` 及其解析 Jacobian。中心化满足：

```text
S_J(0) = 0
dS_J(0) = 0
```

避免 RBF 在零跟踪状态产生无物理意义的常值策略偏置。

### 归一化 HJB 目标

当前性能指标为：

```text
L = ||D1^(-1)s1||^2
  + ||Dz^(-1)z2_bar||^2
  + 0.25*(delta/0.5)^2

D1 = diag([2, 1.5])
Dz = diag([0.5, 0.2])
```

因此物理坐标中的输入权重为 `R_delta = 0.25/0.5^2 = 1`。该写法明确给出各项尺度，避免直接把不同量纲的 `s1`、`z2` 和转向角等权相加。

### 可容许值梯度与 Actor

CARE/LQR 可容许策略为：

```text
delta_admissible = -K0'*Z_F
```

它不再作为 Actor 外的“原控制器 + RL 修正项”人为叠加，而是转化为满足 HJB 驻值条件的控制方向值梯度种子。Critic 和 Actor 分别为：

```text
grad(Jc) = grad(J_admissible) + dS_J'*Wc
grad(Ja) = grad(J_admissible) + dS_J'*Wa

delta_nominal = -(1/(2*R_delta))*C'*grad_z2(Ja)
delta_RL = delta_nominal - delta_admissible
```

Actor 的 Hamiltonian 更新同时使用策略梯度和 `Wa -> Wc` 的共享值函数残差耦合。安全滤波激活时，无法执行的 Hamiltonian 样本不用于 Actor 自适应，只保留权重泄漏；学习关闭时 Identifier、Critic 和 Actor 权重全部冻结。

### 安全投影与真实饱和

安全层把 `delta_nominal` 投影到两个 SFPPB 通道共同给出的标量可行区间，名义区间还与 `[-0.5,0.5]` 相交。当前固定：

```text
safety_lambda = 100
disturbance_bound = [25; 25]
```

真实执行器限制作为 `AGV_ctrl`、`AGV_plant` 和 `assist1` 的统一 S-Function 参数传入，便于在不复制模型的情况下运行饱和压力实验。二维辅助状态保持：

```text
O2_dot = -O2 + C*(delta_applied - delta_safe)
z2_bar = z2 - O2
```

柔性边界辅助状态使用论文中的 `m1 = 5`、`m2 = 0.5`，并由相对超限量驱动；两个误差通道的柔性幅值均为 `0.4`。

## 真实输入饱和与柔性边界压力实验

压力实验只把真实执行器限制从 `0.5 rad` 收紧到 `0.4 rad`；安全层仍按名义 `0.5 rad` 生成请求，因此能够形成真实的请求–执行失配，而不是把安全投影提前收紧后伪造“饱和测试”。

| 指标 | 0.4 rad 压力工况 |
| --- | ---: |
| 仿真终止时间 | `20.000000 s` |
| 最大请求转向 | `0.500000 rad` |
| 最大实际转向 | `0.400000 rad` |
| 最大饱和失配 | `0.100000 rad` |
| 最大 `||O2||` | `0.737329` |
| 最小名义 phi 边界裕量 | `-0.00557446` |
| 最小柔性 phi 边界裕量 | `+0.00168218` |
| 柔性边界激活比例 | `46.2024%` |
| 最大边界放宽量 | `0.0132576` |
| 末端边界放宽量 | `1.53e-9` |
| 安全区间冲突次数 | `8` |

该结果说明：执行器真实饱和时，名义边界确实会被突破；柔性辅助状态随饱和失配扩张边界，保持柔性约束，并在饱和影响消失后回到名义边界。压力工况出现 8 次安全区间冲突，当前实现按最危险通道优先处理，因此该工况不能用来声称两个名义安全集合始终同时前向不变。

因此当前 20 s 执行器可行边界位于 `0.35--0.375 rad`。随着输入能力下降，名义 PPB 很早失效，而柔性 SFPPB 在所有可完成工况中仍保持正裕量并在扰动后恢复；这才是当前最清晰的实验贡献。

| 阶段 | 数值表现 | 结论 |
| --- | ---: | --- |

## 当前仍存在的问题

1. 20/60/120 s 仿真和 0.4 rad 压力实验不是完整稳定性证明。论文仍需给出 Identifier、Critic、Actor、SFPPB、安全投影与饱和辅助系统组合后的 UUB/可行性论证。
2. CARE/LQR 只给出了控制方向上的最小范数值梯度种子；当前 `s1` 种子项与该控制方向梯度尚未严格证明来自同一个全局可积标量值函数。这是下一步最重要的理论缺口之一。
3. 安全滤波在名义主基准中冲突为零，但 0.4 rad 压力工况有 8 次可行区间冲突；最危险通道优先规则不等同于两个通道同时前向不变的证明。
4. 在线 RL 的平均修正方向基本正确，但名义收益小、phi RMS 不一致，30 组联合失配下也未提高成功率。后续重点应是学习模型和安全/SFPPB 理论接口，而不是继续扫描学习率。
5. Identifier 在脉冲扰动窗口仍有明显模型误差。20 s 有效窗口 `RMS ||F_true-F_hat||` 约为 `14.24`，Bellman 模型/数据 residual gap 约占 `3.53%`。
6. HJB 成本目前按请求转向计价；真实饱和压力工况中，请求转向和执行转向不同。最终理论需要明确最优控制目标究竟惩罚命令、实际输入还是二者及饱和损失。
7. `AGV_transfor.m` 仍保留原工程的 `w` 状态接口，但它当前没有进入第一层虚拟控制；后续应在理论推导确定后删除或重新接入，避免无效状态。
8. 项目继续使用原工程的 Level-1 MATLAB S-Function，因此 MATLAB 会给出弃用警告。当前不影响仿真结果，但长期维护可迁移到 Level-2。

## 运行方法

1. 在 MATLAB 中将本目录设为当前文件夹。
2. 打开并运行 `AGV_simulate.slx`；默认仿真时间为 20 s。
3. 运行 `AGV_plot.m` 生成论文图。脚本会额外运行冻结对照、0.4 rad 压力工况和 9 点执行器能力扫描，因此耗时明显长于单次主仿真。
4. 运行 `AGV_diagnose(20,false,100,true,true,0.25,0.5)` 获取完整诊断。
5. 冻结消融使用 `learning_enabled = 0`；0.4 rad 压力实验把最后一个参数和 plant/assist 的执行器限制统一设为 `0.4`。`AGV_diagnose` 与 `AGV_plot` 已自动完成这些临时参数切换并在结束后恢复模型设置。
