# AGV-SFPPB

基于 MATLAB/Simulink 的 AGV 横向控制复现工程。项目以原始 `AGV_TFS` 工程为基础，正在将控制器改造成“滑模柔性规定性能边界（SFPPB）+ 直接 Identifier–Critic–Actor 强化学习”的结构。

> 当前版本属于“结构已经替换、正在稳定性调试”的中间版本。尚未声称完成 20 s 全程稳定仿真或完成论文级结果复现。

上一轮局部修正版只修改了控制器接口，不改变 Simulink 结构：输入饱和辅助状态加入 `C_norm` 缩放，暂时去掉 `w` 对 `alpha_1` 的直接作用，并将第三输出改为全部 Identifier–Critic–Actor 权重的总范数。

当前实验版本进一步只修改 `AGV_transfor.m`：为时变 SFPPB 边界加入解析导数，计算 nominal `Gamma`，并用 `Gamma` 替换继承自原 `AGV_TFS` 的 `T=0.01*TT` 项。该版本尚未通过 20 s 仿真。

上一轮 D1 实验继续只修改 `AGV_transfor.m`：保留 nominal `Gamma`，并令 `D1=diag([2,1.5])` 与现有 `s1y=2*z1_y+...`、`s1phi=1.5*z1_phi+...` 相匹配。该实验同样未通过 20 s 仿真，且数值表现较上一版更差。

最新加权投影诊断冻结 `AGV_transfor.m`，只在 `AGV_ctrl.m` 中使用 `P=diag([3,1])`，并定义统一输入增益 `C_gain=sqrt(C'*P*C)`。`z2_control`、控制律分母和输入约束辅助状态 `O` 现已使用同一个 `C_gain`，从而消除上一轮加权投影中约 46% 的意外控制增益放大。该实验用于检查 y/phi 通道在普通投影中互相抵消的问题，不作为最终二维 HJB/Actor 公式。

## 当前完成情况

- 已建立独立工程目录 `AGV-SFPPB`，保留原 AGV 的 Level-1 S-Function 和 Simulink 端口结构。
- 已修改 `AGV_transfor.m`：
  - 加入 y 方向和航向角 phi 的 SFPPB 上下边界；
  - 保留原有误差变换、滑模变量、虚拟控制量和输出端口顺序；
  - 保留原车辆模型、RBF 网络和 Simulink 连接方式。
- 已修改 `AGV_ctrl.m`：
  - 改为 22 状态 Identifier–Critic–Actor 控制器；
  - 状态划分为 `WF(1:7)`、`Wc(8:14)`、`Wa(15:21)` 和输入约束辅助状态 `O(22)`；
  - 保留 13 输入、3 输出接口，并加入方向盘输入饱和映射；
  - 使用 `dO = -O + C_gain*(k_delta-delta)`，第三输出为 `norm([WF;Wc;Wa])`。
- 已在 `AGV_transfor.m` 的导数和输出计算中同时去掉 `w*eta_1` 对 `alpha_1` 的直接作用；`w` 状态、21 输出顺序和 Simulink 接口仍保留。
- 当前实验版本在 `AGV_transfor.m` 的导数和输出计算中加入 `kappa_dot`、`shift_dot`、nominal 边界导数、`Gamma` 和 `D1` 尺度修正；`AGV_ctrl.m` 未修改。
- 最新诊断版本只在 `AGV_ctrl.m` 的导数和输出计算中加入 `P=diag([3,1])` 加权投影，并统一使用 `C_gain=sqrt(C'*P*C)` 计算 `z2_control`、`delta` 和 `dO`；其余控制参数和学习率保持不变。
- 未修改 `AGV_plant.m`、`AGV_RBF.m`、`assist1.m`、`AGV_plot.m` 和 `AGV_simulate.slx` 的原有结构。

- 两个 S-Function 的直接调用可以正常返回有限数值。
- t=0 时初始误差位于 SFPPB 边界内部，t=5 s 时边界能够收缩到设定终值。
- MATLAB 静态检查未发现问题，控制器接口与直接有限值检查均通过。
- 原始 `AGV_TFS` 控制器作为基线可以完成 20 s 仿真；这说明原模型和原连接基本可运行。
- 上一轮 `3d91b26` 版本可以运行到约 `t=7.0613 s`；在 `t=7.0 s` 时，未饱和转角范围约为 `[-0.00482, 0.00154]`。

## 当前存在的问题

当前 SFPPB-RL 控制器仍然没有通过 20 s 全程仿真。需要区分六个版本的失效现象：

- 修正前版本在约 **t=1.563 s** 失败，曾出现 `e_phi≈0.03650`、上界约 `0.03714`，以及未饱和转角约 `49.38 rad`；
- 上一轮接口修正版本在约 **t=7.0614 s** 附近失败；在 `t=7.0613 s` 时，`e_phi≈0.0049875`，SFPPB 上界约 `0.005`，`w≈1.69`；
- 当前 nominal `Gamma` 实验版本反而在约 **t=2.52 s** 失败；在 `t=2.51 s` 时，`e_y≈0.0212063`、上界约 `0.0212797`，边界余量约 `7.34×10^-5`，`w≈11.22`；
- D1 实验版本在约 **t=1.92 s** 失败；在 `t=1.91 s` 时首先接近的是 y 上边界：`e_y≈0.0168001`、上界约 `0.0169404`，余量约 `1.40×10^-4`；此时 `e_phi≈0.0018742`，距离其上边界仍约 `1.40×10^-2`；
- D1 实验在 `t=1.91 s` 时 `delta≈0.00579 rad`，全程范围约 `[-0.00261,0.00676] rad`，`z1≈[6.758,-0.437]^T`，`z2≈[0.04398,-0.06746]^T`；
- 尺度未闭合的加权投影版本在约 **t=7.063 s** 失败；在 `t=7.062 s` 时 y 上边界余量仍约 `2.49×10^-2`，但 `e_phi≈0.0049379`、phi 上界为 `0.005`，余量仅约 `6.21×10^-5`；
- 该尺度未闭合实验在 `t=7.062 s` 时 `delta≈-0.15598 rad`，全程范围约 `[-0.15609,0.03003] rad`，未发生输入饱和；`z1≈[0.344,5.076]^T`，`z2≈[0.1397,0.2024]^T`。由于控制律仍除以 `C_norm` 而不是 `C_gain`，其运行时间改善不能全部归因于加权投影；
- 最新尺度闭合版本在约 **t=7.05982 s** 失败；在 `t=7.0598 s` 时 `e_y≈0.0052445`、y 上界为 `0.03`，余量约 `2.48×10^-2`，而 `e_phi≈0.00499455`、phi 上界为 `0.005`，余量仅约 `5.45×10^-6`；
- 尺度闭合实验在 `t=7.0598 s` 时 `delta≈-0.12213 rad`，全程范围约 `[-0.12233,0.02412] rad`，未发生输入饱和；`z1≈[0.3533,7.5151]^T`，`z2≈[0.1636,0.2144]^T`，全部网络权重范数约 `0.12667`，`w≈1.9051`；
- 两轮结果支持普通投影存在 y/phi 通道抵消这一判断，但固定 `P=diag([3,1])` 仍把瓶颈转移到 phi 通道，因此它只能作为诊断证据，不是最终控制律；
- 因此，目前不能把该版本的结果表述为“已稳定跟踪”或“已完成论文复现”。

## 运行方式

1. 在 MATLAB 中将本目录设置为当前文件夹。
2. 打开并运行 `AGV_simulate.slx`。
3. 仿真结束后运行 `AGV_plot.m` 绘制结果。

当前尺度闭合的加权投影实验版本预期会在约 7.060 s 附近暴露上述稳定性问题；具体时刻会随 MATLAB/Simulink 求解器步长略有变化。这属于待解决问题的复现实验，不是最终结果。

## 下一步工作

1. 停止继续尝试 `P=5`、`P=10` 等固定权重，根据诊断结果重新推导二维 `z2` 到单转向输入的 HJB/值函数梯度接口，目标形式为 `delta*=-(1/(2r))*C'*grad(J*)`。
